# SNUPI Agent Context

Read `DESIGN.md` before producing any visual artifact. Treat it as the source of truth for colors, typography, layout, and artifact-specific rules.

Use the SNUPI Lab Tech Indigo family:

- primary: `#5B6CFF`
- primary complement (high-contrast callout / CTA): `#FFEE5B`
- slide band / legacy royal: `#4169E1`
- secondary: `#8E97FF`
- accent: `#A855F7`
- neutral ink: `#232833`
- canvas: `#F7F8FF` or white

For presentation slides, preserve the lab template behavior: white canvas, top and bottom blue bands, lower-right SNUPI logo, date/page footer, large title, and one major figure/equation/table per slide whenever possible.

For paper figures and infographics, use white or near-white backgrounds, neutral labels, primary for the main contribution, secondary for support, and accent only for a critical callout. Keep text readable after export.
