# SNUPI Lab Visual Theme Agent Guide

This repository defines the SNUPI Lab Tech Indigo visual family.

Before producing slides, figures, diagrams, previews, or design assets:

1. Read `DESIGN.md`.
2. Treat `DESIGN.md` as self-contained and portable.
3. Optionally inspect `assets/reference/` for visual QA when this repository is available.
4. Prefer the prompt briefs in `brief-prompts/` for artifact-specific work.

Preserve the slide template's white canvas, royal-blue top and bottom bands,
large readable content, and lower-right lab identity when making SNUPI decks.
