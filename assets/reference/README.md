# Reference Assets

This folder stores optional reference material used to build the SNUPI Lab Tech Indigo theme.

- `theme.png`: palette and mood source.
- `snupi_slide_template.pdf`: SNUPI slide layout source.
- `pdf-pages/`: PNG renders of `snupi_slide_template.pdf`, generated with `pdftoppm -png -r 144`.

These files are intentionally kept under `assets/reference/` so every lab member sees the same repo-relative paths. They are useful for visual QA, but `DESIGN.md` is the portable source of truth.
